# Native safe-default planning (noevia#1318)

`native-safe-defaults` moves the read-only plan for `POST /api/v1/sections/{name}/safe-defaults` into Rust, and it is the only path; the former `MODEL_MANAGER_SAFE_DEFAULTS_IMPL` selector is retired and ignored. The route runs on the native models.ini writer. A missing compiled feature, or settings the shared root validator cannot interpret exactly, refuse startup before a child starts.

The planner runs inside the existing admitted blocking writer job while that job owns the models.ini lock. It reuses bounded model discovery, GGUF hints, projector discovery, draft-head search and built-in layer reading. Existing settings win before discovery; claimed files refuse registration; standalone small draft heads and projectors refuse registration. A same-stem build larger than 2 GiB is allowed. Context is capped at 8192, with 8192 when metadata has no positive context. Invalid metadata can still register the model path, matching the Python helper. An external draft head wins over built-in layers. The original sorted first model-file choice and directory projector choice are preserved.

INI writes, backups, cache-ram clamping and response generation use the existing atomic writer. Bounded reads or unsafe paths answer a fixed 503 without exposing paths or changing INI. The native selection never calls `/api/v1/internal/safe-defaults-plan`. The child startup barrier and post-write idle-unload reconcile remain; this feature does not remove the Python process or its DB initialization. The Python planning helper, download planning, token validation and benchmark observation remain separate migrations.

`tools/gen-safe-defaults-oracle.py` runs the actual services app pinned at `60764e67f390ea9dad5c91c3f41aad865d757823`, on synthetic sparse files only. The checked fixture records private plans, public responses and final INI/listings for flat and folder files, repeated/existing sections, inherited claims, bad metadata, small and large draft builds, external versus built-in heads, projectors, defaults and invalid names. Native replay compares all three. Router tests reject child plan calls; path-escape and process-level selector tests cover refusal and feature omission. No weights are loaded or downloaded.
