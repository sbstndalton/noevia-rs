# llama.cpp autoconfig authority

Strict operations 1–6 retain their original algorithms, refusal domain, JSON fixtures and 4 MiB input limit. The public raw APIs use operations 11–12 to execute the entire estimator and confirmation program in Rust. Operation 11 starts a function with an opaque environment reference. Operation 12 resumes the returned state with one mechanical host result or exception.

The generated program contains the complete historical footprint, KV-head mode and period searches, draft spread, inputs, suggestions, and conservative comparison rules. Rust selects every property read, coercion, arithmetic operation, method call and branch. The Node host contains a generic ECMAScript primitive dispatcher, reference management and API error rendering. Rust may supply up to 32 straight-line primitives per response, with a precise continuation for every possible failing operation; conditional branches remain in Rust. Branch-free callbacks are generic compositions selected by Rust data, without source evaluation. It has no estimator source, sizing table, conservative decision or fallback.

Unbounded raw values stay behind opaque references. Objects, iterators, Maps, functions, BigInt and raw non-finite scalars are never eagerly projected. Large scalar strings therefore need no transfer or projection, and arrays are consumed incrementally through the original iterator/method operations. Proven non-Proxy dense Boolean arrays can supply two fixed 4096-bit windows; Rust runs the original period search over those windows, comparing consecutive primitive booleans together without changing its candidate order. Accessors, holes, inherited entries, custom/prototype every methods and Proxies retain the exact observable program. When the same safe Boolean pattern has no per-layer head sequence and its loop coefficients are actual numbers, Rust computes the KV sum in the original multiply/add order with raw f64 values, including NaN, Infinity and negative zero. Object coercions and dynamic or unsafe patterns retain the original operation program. The continuation has 256 stack registers and eight exception registers; the static control-flow test proves the compiled functions fit those bounds. Host reference IDs are recycled after each step. Neither continuation size nor live reference count grows with a processed prefix.

Each invocation and synchronous native callback owns its reference namespace. Closures capture actual lexical environments, including distinct loop-iteration bindings. Abrupt for-of bodies execute the original IteratorClose return lookup/call in Rust-selected order; cleanup faults retain the original thrown completion, while iterator-step/value faults do not close. The module environment is shared, preserving the exported mutable candidate array and KV type metadata table. Legacy raw helper, estimator and conservative-comparison exports are thin calls into this same program. A context stack keeps reentrant calls with different strict loaders isolated.

Rust's confirmation function runs the raw estimator before requesting the original strict operation. That strict request serializes the original argument exactly once. The Rust program then compares the original candidate serialization and applies the frozen conservative rule, including conservative answers when strict serialization throws or exceeds its old limit. Direct autotune footprint sizing invokes the same raw estimator without strict confirmation.
