# Private M6 ChatGPT status policy checkpoint

Refs noevia #1373. This standalone crate is **not an integrated route** and is not a full M6 delivery. The parent workspace, server auth/store/router, corpus, core, supervisor and release files are untouched. Only `crates/chatgpt-status` is owned here.

Implemented: pure disconnected/reconnect/connected status policy; actual masked UTF16 email; arbitrary truthy JSON plan; duplicate-last object members; JS integer-key order; numeric overflow to infinities serialized as JSON null; bounded UTF16 JSON parser and iterative response emission; bounded startup current/previous key snapshot; fd-relative nofollow root components and regular key files; cancellation and two-second CPU deadline checks. `Service::read_with` checks product false before invoking the supplied read closure. That callback is not an implemented SQLite boundary and makes no SQL/auth ownership claim.

Reuse: secret-envelope is directly used for AES-GCM/current-previous/v1-v2 behavior, policy-leaves for JS trim, js-json only for the existing reviewed ECMAScript number formatter. Its existing parser/slice are unsuitable for this status contract because they refuse lone surrogates and numeric overflow. No changes to these dependencies. Keys never call the unbounded SecretKeys::load. Native startup snapshots keys exactly like actual Node createSecretStore; external replacement requires coordinated restart. It creates no key, folder or schema. Regular mounted-filesystem startup I/O is not forcibly cancellable; standard capped allocation is not a hard OOM/RSS guarantee.

Limits: user ID 4096 bytes, row ciphertext 256 KiB, state 64 bytes, replacement-decoded plaintext 192 KiB, JSON 8192 parsed nodes/65536 total string/key UTF16 units/64 recursive parse frames/4 Mi operation work budget, response 256 KiB. Duplicate hash probing is bounded by that cumulative work budget; four fixed radix passes order integer keys. Parse depth is explicitly capped recursion, with iterative output; drop recursion is bounded by the same accepted depth. Root/path 4096 bytes/128 components; fixed 33-byte file read with 64 syscall attempts, accepted key length exactly 32; previous env capped at 4096 bytes before trim/decode. Refusals are stricter than unbounded Node and are intended sanitized 502 at the future HTTP adapter. Ordinary decrypt/malformed JSON remains reconnect.

The CPU control checks before/after the existing bounded AES primitive, at parse/string/probe/emission boundaries, and at the read callback boundary. It spawns no worker. Caller must retain its worker/admission lease through callback, parse, cancellation and completion. It does not prove SQLite cancellation or a hard wall-clock bound on OS scheduling, startup file I/O, allocation or upstream primitive internals.

Qualification uses actual pinned core `010735c7d86d30269ab3f4a351b2135faea1c8e7` via its exported createChatGptOAuth/createProviderRoutes and actual JS envelope implementation. Tiny `tests/oracle.cjs` supplies fake DB/collaborators and only records actual answers/trace. Constructor DDL is recorded only in fake setup; status read/write/network/audit collaborators reject unexpected calls. `node-status.v1.json` binds full source SHA256, seam SHA256 and actual checked Node22.23.3. Its 293 cases include generated UTF16/duplicate/number-bit cases, lone surrogates, overflow, integer key ordering, mask boundaries, malformed values, v1/v2/current/previous/wrong user, invalid UTF8 replacement, feature false and ordinary SQL error mapping at the factory route. Encrypted fixture bytes are random because actual Node encrypt supplies its nonce; regeneration is semantically replayable but not byte-identical ciphertext regeneration. The explicit invalid-UTF8 envelope alone is generated by existing Rust seal, then opened/shaped by actual Node.

Tests include the generated tenant property, startup snapshot vs restart, root/key symlink, FIFO/directory, wrong/missing key lengths, previous-file precedence/env encoding, and named limits. Six actual source mutations must fail the named semantic assertion: first @; Unicode replacement instead of first UTF16 unit; string-only plan; duplicate-first; wrong user binding; missing key NOFOLLOW. Existing c665 bounded process and mutation classifier tools are reused by path for all Git/Node/mkfifo/mutant subprocesses; failed compile/timeouts/unrelated panics are not counted as mutation proof. The mutation example edits and restores only this crate's owned source; don't run concurrently with another writer.
